\section{Per-Phase Verification Status}
Each phase was verified against its corresponding integration testbench
before proceeding. Quantitative results are deferred to
Chapter~\ref{ch:results}.
\begin{itemize}
  \item Phase~0 (single-cycle): all 47 RV32I instructions, register and
        memory state checked. \textbf{PASS.}
  \item Phase~1 (5-stage pipeline): identical expected state at termination,
        120-cycle wait. \textbf{PASS.}
  \item Phase~2 (+BTB): same checks; BTB hit/miss observed. \textbf{PASS.}
  \item Phase~3 (+M-ext, custom-0): hand-assembled 13-instruction MAC
        microbenchmark. \textbf{PASS.}
  \item Phase~4 (+RDCYC, 3-op MAC): all nine benchmarks. \textbf{PASS.}
  \item Phase~6 (validation harness): 27-run sweep
        (9~benchmarks $\times$ 3~configs). \textbf{27/27 PASS.}
\end{itemize}
