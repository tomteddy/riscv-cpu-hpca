\section{Objectives}
\begin{itemize}
  \item Design a 5-stage pipelined RV32I-like processor in Verilog.
  \item Implement RAW-hazard handling via data forwarding plus stalls.
  \item Improve performance with a BTB-based dynamic branch predictor.
  \item Extend the ISA with custom ML-oriented instructions
        (\texttt{MAC}, \texttt{RELU}, \texttt{RDCYC}).
  \item Verify functionally and analyse performance against single-cycle
        and pipeline-without-BTB baselines.
  \item Synthesise on Zynq Z-7020 and analyse post-synthesis timing.
\end{itemize}
